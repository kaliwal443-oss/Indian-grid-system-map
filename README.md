# IndianGridGPS - Android Studio Project (Skeleton)

This is a skeleton Android project for the IndianGridGPS app.
It includes:
- MainActivity + MapFragment (Google Maps)
- Grid overlay & UTM/IndianGrid placeholders
- Gradle files to open in Android Studio

IMPORTANT:
- Replace `YOUR_GOOGLE_MAPS_KEY_HERE` in AndroidManifest.xml with your Google Maps API key.
- This is a skeleton project to build upon. The UTM conversion code is a placeholder.
- To build an APK, open this project in Android Studio and build via Gradle.

Requirements:
- Android Studio Flamingo (or compatible)
- Android SDK and build tools
